## Session: first build of Pilardium

The user had two tools. One was a cost workbook (`Estructura_Costos_Milanesas_Segmentado.xlsx`). The other was a stock app in one HTML file (`Stock Lombardía.html`). The goal was to join both in one simple UI with a backend that writes to the workbook.

**Decisions**

- The workbook is the source of truth for recipes, prices, fixed costs, and capital. See [[cost-workbook]].
- The app keeps stock and the movement log in `data/state.json`. See [[stock-state]].
- One insumo has one price. The app copies this price into the workbook cost column. See [[insumo-price-sync]].
- The UI picks a recipe with two dropdowns: meat (Pollo, Vaca, Cerdo), then recipe. See [[pilardium-app]].

**Files created**

- `app/excel.py`, `app/store.py`, `app/service.py`, `app/main.py`
- `static/index.html`, `README.md`, `run.sh`, `requirements.txt`
- `data/Costos.xlsx` (copy of the original workbook)

**Checks done**

- API test: buy, recipe save, produce, sell, and undo worked. The workbook kept its formulas.
- jsdom smoke test: all five tabs rendered with no script errors.
- No real browser test.

**Open threads**

- The real stock data of the user lives in their Claude account. It is not imported.
- Many recipes in the workbook are incomplete (no prices, no lot weights).
- Etiqueta and bandeja count once per kg of meat in the workbook. The user must confirm this.
- The UI cannot add a new recipe block yet.

## Session: recipe catalog and one function per tab

The user asked to add new recipes from the UI, and to keep one function for each tab.

- The **Recetas** tab is now the catalog. It lists all recipes by meat, with "Nueva receta", edit, and remove. See [[recipe-management]].
- The **Milanesas** tab only holds finished stock: produce, sell, and minimum stock.
- Backend: `POST /api/recipes`, `DELETE /api/recipes/{id}`, and a name field in `PUT /api/recipes/{id}`.
- A new recipe reuses an empty `Indefinido` block. If none exists, the app clones a block and adds a row in the price sheet. The average row moves down. See [[cost-workbook]].
- Tests: API create, reuse, clone, rename, remove. jsdom flow: create, edit, save, back, produce.
